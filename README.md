# CareerMatch AI

## AI-Powered Job Recommendation and Skill Gap Analysis Platform with MCP Server

CareerMatch AI is a machine-learning based career recommendation platform designed to help students discover suitable job roles based on their current skills.

The system recommends relevant careers, identifies missing skills, and provides a learning path to help students improve their career readiness.

---

## Features

- Resume-based skill extraction
- Job recommendations based on user skills
- Machine-learning based skill matching
- Match percentage for recommended jobs
- Skill gap analysis
- Missing skill identification
- Personalized learning paths
- Job search and job details
- MCP-based career tools
- Interactive Streamlit web interface
